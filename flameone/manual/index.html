User manual

What each screen asks for, what it gives back, and the conventions that apply everywhere in the application.

How the application is arranged

One screen answers one question. The sidebar groups the nineteen screens into four families; picking one opens it directly, and the application starts on a usable stoichiometric methane–air case rather than an empty document. There is nothing to create and nothing to save.

Conventions that apply on every screen

Typing a number

Entering a field selects what is already there, so typing replaces the value rather than appending to it. Part-typed numbers such as -, 1. or 1e are allowed to sit in the field while you finish them.

Invalid input is refused, not repaired. A value outside the domain is rejected with the reason beside the field and the previous value stays in use; it is never silently turned into zero or clamped into range. A calculation that quietly used a number you did not type is worse than one that refuses to run.

Digits

Screens show four significant figures, which is what stays readable. Counts — such as a solver's iteration count — are shown as whole numbers, because there is no such thing as half an iteration. Export writes seventeen significant figures, which reproduces the underlying double-precision value exactly, so a downstream calculation gets the same answer you saw.

Units

Everything is computed in SI internally; conversion happens only at the boundary, where you type and where the result is displayed. Each field states its own unit, and each result carries the unit it is reported in.

Where a relation has more than one solution

Both are shown. Strong and weak branches, ignition and extinction turning points, frozen and equilibrium flame temperature — the application does not choose one for you, because which one applies is a property of your problem and not of the arithmetic. Where a modelling choice has to be made, it is a visible control on the screen rather than an internal default.

What each screen tells you about itself

Every screen carries the relation it uses, under Relation used, and a standing note of what the model does not cover. Those notes are not dismissible: the limits of a model are part of its answer.

Exporting

Export CSV in the toolbar writes the conditions, the results and the stated limitations as one file, at seventeen significant figures. Charts have their own PNG and PDF buttons: PNG at 2× for a report, PDF as vector for typesetting. Every export carries the conditions it was computed under and the version that produced it — a curve with no stated conditions cannot be checked by anyone, including the person who exported it.
