ThrustOne Support

Help with model selection, calculations, case files, and exports.

Getting started

  1. Create or open a native .thrustone case. Its content is ordinary JSON; existing .json cases remain importable.
  2. Select an engine category and a model. Read its assumptions and limits before interpreting the results.
  3. Edit the input form, or edit the case JSON and apply it. Use the units shown beside each input; internal calculations use SI units.
  4. Run the calculation and inspect the numerical results, charts, and warnings.
  5. Save the case for later, or export results and charts from the available export commands.

Inputs and calculations

If a field is marked invalid, finish editing it and enter a finite number within the displayed bounds. Changes to a JSON draft must be applied before calculation. A failed calculation does not certify that the physical design is impossible: check the selected model's assumptions and input domain.

Parameter studies support up to 1,000 total points. Local one-dimensional optimization requires a suitable bounded interval and a unimodality assumption; it is not a global design optimizer.

Contact support

Email softwareone.support@gmail.com. Include your app version, macOS or iPadOS version, selected model, steps to reproduce the issue, and a small non-confidential example if useful. Do not send sensitive or proprietary data.

ThrustOne is an English-only application for Apple silicon Macs running macOS 12 or later, and iPads running iPadOS 16 or later.
